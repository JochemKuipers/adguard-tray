adguard-tray

Unofficial Debian package of RiDDiX/adguard-tray. Debian 12+, Ubuntu 24.04+, and other apt-based systems.

Install

curl -fsSL https://jochemkuipers.github.io/adguard-tray/install.sh | sudo bash

Or add the repository yourself:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://jochemkuipers.github.io/adguard-tray/adguard-tray.asc \
  | sudo tee /etc/apt/keyrings/adguard-tray.asc >/dev/null
echo 'deb [signed-by=/etc/apt/keyrings/adguard-tray.asc] https://jochemkuipers.github.io/adguard-tray stable main' \
  | sudo tee /etc/apt/sources.list.d/adguard-tray.list
sudo apt update
sudo apt install adguard-tray

Updates: sudo apt update && sudo apt upgrade
